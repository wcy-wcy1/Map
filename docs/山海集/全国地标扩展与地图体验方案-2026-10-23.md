# 山海集｜全国地标扩展与地图体验方案

日期：2026-10-23。状态：开发提案；本轮完成源码梳理与选题研究，未实施功能改动或性能验收。

## 1. 推荐方向

把地图做成一张能逐步展开的地方旅行图鉴：全国看各地气质，进入省区看少量代表景点，选中地点后看自己的照片与手记。

沿用现有摄影册／手账风格。各地辨识度主要来自建筑与地貌轮廓，颜色只作辅助。一个省区首轮选 4 个地点，按「2 个经典地标＋2 个地方发现」编辑；“地方发现”对应地方建筑、聚落、工业遗产、湿地或文化景观，不承诺游客少，也不冒充实时热度榜。

先做北京、四川共 8 个地点，验证城市密集区与大尺度自然地貌；再补浙江、福建、广西、甘肃、贵州、新疆共 24 个。最后把同一流程扩展到其余 25 个省区。若全部每省 4 点，新增 132 点，加上原云南 43 点，共 175 点。已有云南内容保留，用展示层精选避免一省过密、其他省过空。

## 3. 三级地图体验

### 全国：先辨认地方，再进入

- 保留省区轮廓、可点击省名，以及真实足迹摘要。
- 代表地标按视窗和碰撞情况精选显示：桌面先以 8–12 枚、手机以 4–6 枚为调试预算，属于上限而非必须填满。
- 不同时铺满 34 枚大图，更不在全国层把 175 个地点全部放开。省名与筛选入口始终能找到被隐藏的地区。
- 北京可用宫殿屋顶、四川可用分水堰或雪峰、福建可用土楼、甘肃可用沙丘和关城。图形带名称；国别／省区轮廓不因装饰而拉伸或移动。
- 进入与返回时记住原来的中心、缩放和筛选，避免每次回到默认位置。

### 省区：经典地标与地方发现一起呈现

- 默认显示首批 4 个精选地点，有经典也有地方特色；提供「全部精选／经典地标／地方发现」，与现有「全部／有回忆」维度明确区分。
- 每个地点一枚图形、真实地名和一行具体特色，例如「圆形夯土围合建筑」「石拱桥与水乡街巷」。卡片文案不堆“宝藏”“绝美”等空泛描述。
- 地点相邻时使用聚合入口；展开后仍可从列表选择，不为了塞下图案修改坐标。
- 云南现有 43 点全部可检索，省区初始视图只按优先级精选，放大或筛选后展示更多。
- 新疆等跨度大的地区，先展示全省轮廓与全部候选分布，再由用户进入局部；不把远隔多地的点伪装成一条短途线路。

### 地点：照片、手记与地标有明确主次

- 无回忆：显示地标、简介和“记一下”。有回忆：用户照片和记录优先，地标作辅助识别。
- 选中地点和当前照片优先布局，其次其他有回忆地点、经典地标、地方发现与普通标签；筛选“地方发现”时相应提升其优先级。
- 插画、照片、标签与按钮共用屏幕空间预算。真实锚点固定，允许插画／照片偏移并以引线连接。
- 地标表示地点身份；“去过”仍来自 Visit。浏览或点击公共地标不增加足迹。

## 4. 图形与版面规范

### 地标风格

延续现有 SVG 轮廓：80×72 逻辑画布，底部 `(40, 68)` 对应地理锚点。默认显示约 48–64px，选中时可到 72px，但布局计算必须使用实际占位尺寸。手机交互区不小于 44×44px。

每枚图用一个主轮廓和两三个辨识细节。例如天坛突出蓝色三重圆顶；都江堰突出鱼嘴分水结构；土楼突出环形围合；侗寨鼓楼突出层叠屋檐。自然景观需区分雪峰、喀斯特、丹霞、沙丘和湿地，不以换色作为唯一差别。

基础色继承现有设计：纸白 `#FBF8EF`、墨绿 `#163D3A`、草木 `#CCDCC8`、水蓝 `#A9CED3`、朱砂 `#A23E34`，辅色用现有沙金 `#D2AE65`。省区以“形状＋名称＋少量点缀色”区分，不新增 34 套主题。深色模式沿用语义令牌并逐枚核对清晰度。

名称用真实文本而不是画进图中；标题沿用现有宋体，操作和地名保持系统无衬线。图形从可信静态注册表加载，未知 iconKey 使用现有回退图，不接收任意远程 SVG 字符串。

首轮 32 点交付 32 个可辨识的组合／专属变体，可复用底层路径。每点同时提供简化表现和常规表现，优先通过同一 SVG 的细节层实现，避免重复资产。全国选用其中 8 个代表图；不增加大尺寸位图作为标记。

### 版面

桌面：上方为当前地区、搜索和精简筛选；左侧地图占主要空间，右侧保留约 320–360px 的地点列表／详情。详情展开不改变地图容器宽度，减少重排。

手机：顶部保留地区返回与搜索，地图作为主要视窗，底部用可收起详情面板。先显示一行地点摘要，用户主动展开后显示照片与手记；点击标记时将地点平移到面板上方的可见区。面板必须支持按钮和键盘，不以手势为唯一操作方式。

## 5. “丝滑”的实现要求

| 用户动作 | 目标体验 | 实现方向 |
| --- | --- | --- |
| 全国进入省区 | 位置关系清楚，细节渐进出现 | 约 300–450ms 的有界视图过渡；长距离切换采用短淡入，避免跨半张地图飞行 |
| 点击景点 | 先立即选中，再轻移到可见位置 | 约 180–280ms 平移；已在可见区域的地点不强制重新居中或放大 |
| 打开详情 | 地图和照片保持稳定 | 固定桌面栏尺寸；手机面板约 180–240ms transform/opacity 过渡 |
| 缩放与拖动 | 图标随底图移动，结束后稳定展开 | 运动中使用地图本身的变换；结束后合并一帧更新，按稳定 ID 更新／复用节点 |
| 快速连点省区 | 始终响应最后一次选择 | 中断旧视图动画，复用现有取消与迟到结果隔离机制，并推广到图形／细节资源 |
| 返回上一层 | 回到刚才浏览的位置 | 按省区保存视图；关闭详情时不重新 fitBounds |
| 资源慢或失败 | 轮廓与地点列表仍可操作 | 先展示常驻元数据，细节延迟加载；失败提供重试，回退到简化地标 |

动画时长是初始设计参数，必须结合实际设备调试。尊重 `prefers-reduced-motion`，减少动效时立即定位；照片解码和无关数据加载不能阻塞点击反馈。

布局需增加“迟滞”：在聚合／展开阈值之间留一小段缓冲，优先沿用上一轮布局，避免轻微缩放让标记来回跳。图标避让结果稳定排序，选中项不因优先级重新排序而丢失键盘焦点。

## 6. 数据与工程拆分

1. **统一目录构建。** 为每点明确稳定 ID、mapId、regionId、名称与别名、WGS84 坐标、代表点语义、来源和内容版本。保留旧云南 ID。生成前后端共用的清单、数量与校验和，拒绝来源不明或归属冲突的数据。
2. **把内容分类与布局权重分开。** 可新增 `discoveryTier: 'classic' | 'local'` 与 `themeTags`；现有 `priority` 只控制显示顺序，不代表热度。新增字段属于公共目录，不必写进每条私人回忆。
3. **常驻少量地点身份元数据。** 本轮仅到约 175 点，继续常驻可解析索引，包括 name、regionId、coordinates、iconKey 等；先不引入可卸载地点身份分片。按省延迟加载的是图形包和地图细节，避免“分片没加载”被误判为旧回忆地点不存在。
4. **图形注册表模块化。** 保留 `svg(key, {variant: place.id})` 的调用与安全边界，拆公共类别和省区专属图形；加载前使用简化类别图，不改变 placeId。
5. **地图分层与增量更新。** `FootprintMap.vue` 分离边界、地标、照片、标签、路线的更新条件；用稳定 ID 保存标记／照片视图。选择变化只更新相关样式，数据变化才重新计算必要图层。先把标签中心与 feature bounds 从每次标记重绘中移出，按 geography 对象缓存；保留已有 requestAnimationFrame 合帧，再拆分深度 watch。
6. **统一遮挡布局。** 基于现有 `cover-layout.ts` 扩展完整占位，纳入地图控制器、详情面板、标签和安全区。先做可控数量的碰撞计算，性能录制证明有需要后再考虑空间索引或 Worker。
7. **后端与备份兼容。** 后端接受新目录版本和新点；已有云南记录、旧目录引用、草稿、封面与备份持续可解析。不能通过直接改常量或关闭校验解决版本不匹配。回退 UI 时需保留已写入新地点的最小解析目录。

主要落点：`domain/catalogue.ts`、`domain/models.ts`、`data/`、`map/landmarks.ts`、`map/presentation.ts`、`domain/map-layout.ts`、`map/cover-layout.ts`、`components/FootprintMap.vue`、`components/PlaceDetail.vue`、`App.vue`、`styles/journal.css`、`services/geography-service.ts`、`scripts/sync-reference-assets.mjs`、`shanhai-api/src/catalogue.ts`。生成清单／省区图形文件属于计划新增项。

## 8. 验收标准

- 内容：每个新省区 4 个可追溯点、经典与地方发现各 2；图形在 48–64px 下具有明确差别，名称、归属和来源能核对。人气分类属于编辑选择，页面不显示虚构游客量。
- 地理：坐标系与锚点语义明确；不以移动坐标解决碰撞，不把省区示意图包装成导航或标准地图。临近海岸／省界等粗边界疑点先核对，不强行放宽数据验证。
- 操作：全国→省区→地点→返回完整；连续切换 10 次后仅最后一省生效；搜索未显示图标的景点仍可找到；按钮、键盘、触屏与减少动效模式可用。
- 数据：云南旧记录和新省区记录都完成创建、刷新、检索、编辑、封面、备份回导；现有个人照片不因切图重新归属或丢失。
- 视觉：桌面 1440px，以及手机 320／390／430px；浅色、深色均检查。控件不遮挡选中地点，详情关闭恢复原位置。桌面窄屏检查与真实手机结果分开记录。
- 性能：实施前固定浏览器、设备、视窗、资料量与缓存状态，对比当前 43 点、首批 75 点和目标 175 点；另用 1000 个合成个人点检验降级／聚合。
- 性能初始目标：点击后 100ms 内出现选择反馈；热缓存省区切换 500ms 内完成主要过渡；拖动期间以 60fps 为优化目标，P95 帧间隔先以不超过 33ms 为验收参考；交互路径避免连续超过 50ms 的主线程长任务。以上均为待测目标，不是当前性能宣称。
- 资源：全国首屏不加载全部省区图形包和细节几何；在相同构建口径下首载传输预算尽量不高于当前基线。完成录制后再确定最终字节上限，新增内容不得引入全库照片读取。
- 测试：扩展现有 catalogue、landmarks、map-presentation、map-cover-layout、footprint-map、national-map-ui、geography-service 与备份测试；后端验证新公共点、旧版本引用和身份隔离。阶段交付运行前端 verify，目录／后端变更时运行后端相关集成测试。

本轮产物仅为方案。运行浏览器预览工具未提供可用的通用浏览器，因此没有把页面观测或帧率当成本轮证据；临时开发服务已停止。实施时需要补实际页面对比和性能录制。
